01

적용 범위와 기본 원칙

이 방침은 autumnkyoto.com에서 제공하는 일정별 교토 예약 가이드에 적용됩니다. 외부 링크를 통해 이동한 예약 판매처와 서비스 제공자의 개인정보 처리는 각 사업자의 별도 개인정보 처리방침과 약관을 따릅니다.

현재 사이트는 여행 상품을 직접 판매하거나 결제받지 않습니다.

사이트 운영자는 외부 판매처의 예약 단계에서 이용자가 입력하는 개인정보와 결제 정보를 직접 수집하거나 저장하지 않습니다.

02

직접 수집하는 개인정보

현재 AUTUMN KYOTO에는 회원가입, 로그인, 뉴스레터 신청, 웹 문의 양식 또는 직접 결제 기능이 없습니다. 다만 이용자가 contact@autumnkyoto.com으로 문의하면 발신 이메일 주소, 메일에 표시된 이름과 이용자가 직접 작성하거나 첨부한 내용이 문의 응답을 위해 처리됩니다.

  • 처리 목적: 사이트 내용, 제휴 안내 및 운영 관련 문의 확인과 답변
  • 보유기간: 문의 처리 완료 후 불필요해지면 삭제하며, 분쟁 대응이나 법령상 보관 의무가 있는 경우에는 필요한 기간 동안 보관
  • 주의사항: 예약번호, 여권 정보, 카드 정보 등 민감한 예약·결제 정보는 보내지 않아야 하며 예약 변경·취소·환불은 해당 판매처에 문의

향후 회원·분석 기능을 추가하는 경우에는 실제 처리 항목, 목적, 보유기간과 외부 제공 여부를 이 방침에 먼저 반영합니다.

04

외부 예약 사이트에서의 처리

숙소, 교통, 체험 버튼을 누르면 외부 예약 판매처가 새 창에서 열립니다. 해당 사이트에서 입력하는 예약자 정보, 탑승객 정보, 여권 정보와 결제 정보는 외부 판매처가 독립적으로 수집·처리합니다.

  • 예약 전 외부 판매처의 개인정보 처리방침과 약관을 확인해야 합니다.
  • 예약 정보의 열람·정정·삭제·환불 문의는 예약을 진행한 판매처에 요청해야 합니다.
  • 사이트 운영자에게는 제휴 성과 확인을 위한 비식별 또는 집계 정보가 제공될 수 있으나, 외부 결제 화면에 입력된 개인정보를 직접 열람하지 않습니다.
05

일정 저장 기능과 삭제 방법

‘이 일정 저장하기’를 선택하면 여행 기간 코드가 브라우저의 로컬 저장소에 저장됩니다. 이 정보는 서버로 전송되지 않으며 이름이나 연락처와 결합되지 않습니다.

삭제 방법

  • 저장된 일정 버튼을 다시 눌러 저장을 해제합니다.
  • 또는 브라우저 설정에서 autumnkyoto.com의 사이트 데이터·로컬 저장소를 삭제합니다.

브라우저 데이터가 삭제되거나 저장이 해제되면 해당 일정 정보는 더 이상 기기에 남지 않습니다.

06

이용자의 권리와 보호 방법

이용자는 브라우저에 저장된 일정 정보를 언제든지 직접 삭제할 수 있습니다. 이메일 문의 과정에서 제공한 정보의 열람·정정·삭제를 요청하려면 contact@autumnkyoto.com으로 연락할 수 있습니다. 외부 예약 판매처가 처리하는 개인정보에 관한 권리는 해당 판매처의 개인정보 처리방침에 따라 행사해야 합니다.

개인정보 침해 상담과 분쟁조정이 필요한 경우 개인정보침해 신고센터 또는 개인정보 포털을 이용할 수 있습니다.

본 사이트는 별도 웹 문의 양식을 운영하지 않으며, 공개 문의 채널은 contact@autumnkyoto.com입니다.

07

만 14세 미만 아동의 정보

본 사이트는 만 14세 미만 아동의 개인정보를 의도적으로 직접 수집하지 않습니다. 외부 예약 서비스에서 아동 또는 법정대리인의 정보를 입력하는 경우 해당 판매처의 연령 기준과 개인정보 처리방침을 확인해야 합니다.

08

개인정보처리방침의 변경

사이트 기능, 외부 서비스 또는 관련 기준이 변경되는 경우 이 방침을 수정할 수 있습니다. 새로운 개인정보 수집 기능을 도입하는 경우 적용 전에 처리 항목과 목적을 이 페이지에 반영하며, 시행일을 함께 표시합니다.
